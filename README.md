# Maruthi Yenumula: portfolio

React + Next.js (App Router), Tailwind CSS v4 and GSAP. Prerendered portfolio pages with cinematic text reveals and dark/light themes.

```bash
npm install
npm run dev      # http://localhost:3000
npm run build    # production build
```

## Edit the content

Everything on the site comes from `lib/data.ts`: profile, experience, projects, skills, education.

The displayed experience duration is calculated automatically from February 2026, using calendar months in India time. It updates on page load and at month boundaries without a rebuild. The PDF uses the joining date instead of a duration so it does not become stale.

- **Profile photo:** the hero uses `public/profile-office.png`, configured through `profile.photo`. Set it to `null` to hide the image.
- **Skills:** every group with a nonempty `strong` list appears on the homepage, including DevOps & Cloud.
- **Resume button:** copy the resume PDF into `public/` and set `profile.resumeUrl` (for example `"/Maruthi_Yenumula_Resume.pdf"`). The buttons stay hidden while it is `null`.
- **F2Home live link:** set `live` on the F2Home entry. The demo button appears when a URL is configured.
- **Screenshots:** WebP files in `public/projects/<project>/`. `scripts/media.mjs` shows how the originals were converted.
- **HRMS case study:** `app/case-studies/hrms` includes Task Management alongside the other HRMS modules. The interactive demos use sample data.

## Deploy

`/sitemap.xml` and `/robots.txt` use the Vercel production domain automatically. Set a `SITE_URL` environment variable (for example `https://yourname.com`) if you attach a custom domain.

The fallback production origin is `https://maruthi-portfolio-iota.vercel.app`, the existing portfolio URL. No monthly experience setting or additional URL setting is required for this deployment.

Push to GitHub, import the repo in Vercel, and deploy.

The build command is `npm run build` (webpack). This avoids the Turbopack CSS worker failure observed on Windows. Keep the framework preset as Next.js and let Vercel choose the output directory. Use `npm ci` for reproducible installation.

Before sharing the production URL:

- Set `SITE_URL` to the final origin if automatic Vercel domain detection does not apply. Rebuild after changing it.
- Check `/robots.txt` and `/sitemap.xml` reference that domain.
- Check the resume download, contact links and project source/demo links.
- Check both designs, light/dark modes, and mobile navigation in a browser.

`npm run typecheck` checks TypeScript. `npm run lint` runs ESLint.

The resume is generated by `scripts/build_resume.py` using Python and ReportLab. Its original backup lives only under the ignored `tmp/pdfs/` folder, outside public assets.
